# 等一會兒

一座漂浮在夜空里的小岛，岛上有一间亮着灯的木头小屋。

单文件 3D 动画：用电脑浏览器直接打开 `index.html`，点一下「點一下，進門」，然后就交给镜头。

- 先远远绕岛一圈，再一处一处介绍：小屋、红灯笼、台阶上的玫瑰、褪色的红色塑胶小铲子、窗台上的毛绒白菜／弯月亮抱枕／橡皮小青蛙、鸡窝里的小章鱼和小狐狸、半剖开的蜂箱（八只蜜蜂，一只樱粉色）、萤火虫、膽小純情男大（尾巴尖是白色的雾脊貘）、待月亭里坐着的人、池底推石头的橙蛸。
- 最后停在亭子和池塘之间，慢慢呼吸；流星继续划过，偶尔灯笼亮一下、橙蛸吐一个爱心泡泡、窗里的灯暖一档。
- 所有模型、贴图、声音都是代码现场生成的，没有外部图片、模型或音频文件。

## 技术

- three.js `0.184.0`（`three/webgpu` 的 `WebGPURenderer`），从 cdn.jsdelivr.net 用 importmap 引入；不支持 WebGPU 时自动回退 WebGL2，两者都不行或 CDN 连不上时显示提示卡，不会白屏。
- 卡通着色（`MeshToonNodeMaterial`）+ 柔和辉光（bloom，阈值偏高，不过曝）+ 月光阴影。
- 配乐用 Web Audio API 现场合成：D 大调五声音阶的八音盒华尔兹，每一遍都有一点小变化；底下是风声和虫鸣；风铃、流星、泡泡各有自己的声音。点了入口才开始放声音。
- 字体：Google Fonts 的霞鹜文楷 TC（只按页面用到的字子集加载）。
- 系统开了「减少动态效果」时：镜头放慢、漂移变小，星星、萤火虫、灯笼不闪烁，流星变少变慢。

## 调试用网址参数

- `?auto=1` 直接进门（不放声音）
- `?t=秒数` 从故事的某一秒开始，`&hold=1` 让镜头停在那一刻
- `?webgl` 强制使用 WebGL2
- `?rm` 模拟「减少动态效果」
