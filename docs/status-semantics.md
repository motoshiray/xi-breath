# 状态语义

状态必须同时以文字表达，不能只依赖颜色、图标或位置。

| 状态 | 最小语义 | 不代表 |
| --- | --- | --- |
| `FRESH` | 最近存在一条有效自报 | 永久状态、客观诊断 |
| `STALE` | 存在旧自报，但时效已过 | 旧内容仍是“此刻” |
| `NONE` | 尚未收到主体自报 | 没有感受、拒绝表达 |
| `DECLINED` | 主体明确选择本次不报 | 负面、冲突、永久拒绝 |
| `CLEARED` | 主体明确表示先前状态已过去 | 删除历史、从未发生 |

## 推荐投影顺序

1. 若最新有效事件是 `DECLINED`，显示本次拒报。
2. 若最新有效事件是 `CLEARED`，显示已撤回，不复用旧值。
3. 若没有任何有效自报，显示 `NONE`。
4. 若存在自报且仍在实现者明确声明的时效范围内，显示 `FRESH`。
5. 若存在自报但超过时效，显示 `STALE`，同时保留原始绝对时间。

“时效范围”不是心理学事实，只是界面策略，必须可配置并在文档中说明。

## 订正

错误记录不能静默覆盖。新增一条 `correction`，通过 `corrects_report_id` 指向被订正记录。投影可以展示订正后的当前视图，但审计历史保留原文及订正关系。

旧 `report_id` 不应通过修改指纹后重新发送。正确方式是创建新的 `report_id` 并显式引用旧记录。
